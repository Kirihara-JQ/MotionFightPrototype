# V2.0 修订说明：Level 1 / CircularArea 场景基线

日期：2026-10-29

本版本根据项目总方案、SRS V1.5、数据接口 v0.3 和 C 成员原详细设计修订。

## 不再采用的旧路线

- 不再新建空白 Arena 作为主场景。
- 不再从 Level 1 抽取少数环境资产后删除/清理原关卡。
- 不再默认用 Quaternius Humanoid 替换 Ellen 或用新怪兽替换 Level 1 现有怪兽。
- 不再让 Game Kit 原始控制器、旧 Damageable 与新战斗系统同时控制/扣血。

## 新的固定基线

1. Unity 6000.3.27f1 + URP。
2. 原始 Level1 只读；Save As 新建 `Level1_CircularArena_Combat.unity`。
3. 保留副本内 Level 1 全部场景对象、人物、灯光和资源。
4. CircularArea 及周边环境构成战斗竞技场；准确尺寸/路径以本机 Hierarchy 和 Scene Audit 为准。
5. 通过 `__CombatOverlay` 新增战斗逻辑，引用现有 Ellen 与一只指定现有怪兽。
6. 非参战角色保留对象和外观；如与 1v1 冲突，只在副本中按显式清单停用原 AI/攻击/伤害行为。
7. 当前 MVP：键鼠移动、左右直拳、格挡、怪兽 AI、双方血量、胜负/平局、暂停/重开与事件日志。踢腿、闪避/翻滚、复杂连招和多人同时参战不纳入首版。
8. 补充动画仅在现有角色缺少所需 Clip 时，通过真实 Clip Map 和 Avatar 重定向实测后接入。音效按 CC0 清单择需使用。
9. 所有未运行的验证结果标为 Not Run；文档不代表场景已经被自动修改或游戏已通过测试。

## 需求范围口径

较早的总体方案曾把闪避、体力等魂类机制列入更完整的目标。为避免与最新细化规则冲突，本版实现以 2026-10-28 的《1v1 三维格斗场景与规则》及 SRS V1.5 为当前 MVP 验收口径：真实移动/转向、左右直拳、一种格挡、一只电脑怪兽、双方 HP、命中反馈、胜负/平局、暂停恢复、重开和事件记录。踢腿、闪避/翻滚、体力条、连招、多敌人同时参战均属于后续扩展，只有团队明确变更需求后才纳入。
